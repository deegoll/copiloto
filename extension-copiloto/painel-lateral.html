Sincronização

Automática a cada 3 horas, com o Mercado Livre deste Chrome.

Custos

—

  1. No Tiny: Início › Extensões › Token API › Instalar.
  2. Depois: Configurações › E-commerce › Token API › Copiar.
  3. Cole aqui e clique em Conectar. O Copiloto só lê o custo. Não muda nada no Tiny.

Conectado, o ERP importa os custos sozinho a cada sincronização. Omie: na página de custos. Bling: importe a planilha.
